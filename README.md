# ko-paper-explainer: SFT vs SFT+DPO

영어 AI 논문 초록(arXiv)을 학부생 눈높이의 쉬운 한국어로 설명하는 소형 언어모델을 만들고,
**SFT만 한 모델과 SFT+DPO 모델을 비교**하는 프로젝트입니다.

> 진행 중인 프로젝트입니다. 결과는 실험이 끝나는 대로 채워집니다.

## 연구 질문

1. 도메인 특화 SFT는 같은 크기의 범용 Instruct 모델보다 얼마나 나은 설명을 만드는가?
2. DPO는 SFT 위에 무엇을 더 개선하는가? (사실 충실도, 이해하기 쉬움)
3. DPO의 부작용은 무엇인가? (답변 길이 증가, 원문에 없는 내용 생성, 일반 능력 저하)

## 실험 설계

| 모델 | 설명 |
|---|---|
| A. Baseline | `Qwen/Qwen3-1.7B` 공식 모델 (thinking 모드 끔) |
| B. SFT | A + 논문 설명 데이터로 LoRA SFT |
| C. SFT+DPO | B + 선호 데이터로 DPO |

세 모델 모두 같은 평가셋, 같은 생성 설정으로 비교합니다.

## 데이터

| 구분 | 규모 | 내용 |
|---|---|---|
| 평가셋 | 100~200개 | 학습에 절대 사용하지 않음 |
| SFT 데이터 | 1,000~3,000개 | 논문 초록 → 쉬운 한국어 설명 |
| DPO 선호 데이터 | 500~1,000쌍 | B 모델이 생성한 답변 중 더 나은 답 / 못한 답 쌍 |

세 데이터는 서로 다른 논문으로 구성해 평가 결과가 오염되지 않도록 합니다.

## 평가

- **사실 충실도**: 원문 초록에 없는 내용을 지어냈는지
- **설명 품질**: 이해하기 쉬움, 핵심 전달, 간결성 (기준표 기반 LLM 채점)
- **B vs C 일대일 승률**: 답변 순서를 바꿔 두 번 채점해 위치 편향 제거
- **부작용**: 답변 길이 변화, 일반 능력 변화
- **사람 평가**: 30~50개로 LLM 채점 결과 검증

## 환경

- GPU: NVIDIA RTX 5060 (8GB VRAM), LoRA 학습
- 주요 라이브러리: `transformers`, `trl`, `peft`

## 폴더 구조

```
configs/   학습 설정 (SFT, DPO 하이퍼파라미터)
data/      데이터셋 (용량이 큰 원본은 git에서 제외)
scripts/   데이터 수집, 학습, 생성 스크립트
eval/      평가 스크립트와 채점 기준표
reports/   결과 표, 그래프, 분석
```
